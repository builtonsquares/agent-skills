Observations for Phase 3:
1. **Missing tests when the repo has no test setup:** three findings with the same root cause inflated the count. **Decided:** one medium finding for the whole diff (severity.md fixed rule 1, quality.md).
2. **5 findings on 6,248 lines from one sequential pass.** Precision looks high, but recall on a diff this size is unmeasured. That supports parallel per-lens reviewers (Task 10), and possibly splitting very large diffs into chunks.
3. ASK_FIRST worked: Cursor asked "How should I scope this read-only review?" with "Review all 148 committed changes (Recommended)", and the user picked it.
4. The base rendered as `origin/HEAD`. **Fixed:** collect.sh now resolves it to the branch it points to (`origin/main`), verified on a fixture.
